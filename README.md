# S3 Backend Oefeningen

In de folder [opdrachten](./opdrachten) vind je per les een aantal oefenopdrachten.

In deze repository willen we dat je alles 'from scratch' opbouwt.

## Procedures:

Commit Vaak!

* In elk geval na elke oefening
* Maar ook als je ergens vastzit
* Of als je een deeloplossing hebt

Basically, de meeste van jullie committen veeeeels te weinig, dus train jezelf in minder `CTRL-Z`, en meer `git commit`.

Push minstens dagelijks, idealiter elk uur (dat je er mee bezig bent natuurlijk).

Lever je opdracht voor die les in op Canvas als je het zelf af vindt en feedback zou willen.

Je werk op deze opdracht is puur formatief, dus leuk als het goed gaat, maar geen probleem als dat niet zo is.
(kortom, als het goed gaat vind ik het, een klein beetje, meetellen als bewijs, maar je hoeft het niet te compenseren ofzo als het niet goed gaat
dan is het gewoon geen bewijs van wat-dan-ook).

## AI-clausule

Het is niet de bedoeling dat je een agent code voor je laat genereren, 
juist dat je zelf een scherper beeld krijgt hoe de technische lijntjes lopen.

Het is vervelend, zonder moeite gaan je hersenen niet echt aan, en leer je minder. En een Agent maakt het net
te soepel en te makkelijk, en we willen dat je een dieper begrip van deze zaken krijgt, zodat je beter in staat bent
om output van je collegas (synthetisch of menselijk) te kunnen beoordelen en aanpassen.

Uiteraard is het prima om een agent als student-assistent of 'interactieve zoekmachine' te hanteren. 
Probeer dan ook te vragen naar het waarom, en bijv. hoe dit zou werken in Node+Express.
